# Better Item Overlay

[![Modrinth Downloads](https://img.shields.io/modrinth/dt/better-item-overlay?logo=modrinth&logoColor=%2300AF5C&color=%2300AF5C)](https://modrinth.com/mod/better-item-overlay)
[![CurseForge Downloads](https://img.shields.io/curseforge/dt/403900?logo=curseforge&logoColor=%23F16436&color=%23F16436)](https://www.curseforge.com/minecraft/mc-mods/better-item-overlay)

Minecraft mod for displaying additional information about items on the item itself - in the hotbar and in every inventory.

Built with [Stonecraft](https://stonecraft.meza.gg/) (Stonecutter + Architectury) for Fabric, NeoForge and Forge across multiple Minecraft versions.

## Features

- **Durability number** - the exact durability left on tools, weapons and armor, coloured like the durability bar or in a colour of your choice
- **Arrow counter** - how much ammo your bow or crossbow has left, with ∞ for Infinity
- **Enchantment icons** - pick an icon for each enchantment (e.g. a diamond for Fortune, glass for Silk Touch) and see an item's enchantments without opening its tooltip
- **Potion effect icons** - the effects of potions, tipped arrows and suspicious stews
- **Waxed icon** - tells waxed copper blocks apart from unwaxed ones
- **Sulfur cube buckets** - shows which block a bucketed sulfur cube has absorbed (26.2+)

## Configuration

Every overlay can be configured in-game, with live previews in the config screen:

- Show each overlay **always**, **never**, or only **while holding a key** - separately for the hotbar and inventories
- Choose the position and size of every overlay, or use one general size for all of them
- Single, stacked or side-by-side layout when an item has several icons
